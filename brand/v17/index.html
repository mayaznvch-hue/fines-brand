Айдентика

Айдентика ювелирной витрины: гильош из медных дуг, тонкие рамки-паспарту, клеймо-монограмма и номер изделия курсивом. Много воздуха, мало элементов.

Паттерн

Гильош: концентрические медные дуги из двух углов, шаг 14 px. Только на тёмном фоне, не больше одного блока на макет.

07

Баннеры

Баннеры как витрина: чёрный бархат, медная рамка, крупная антиква и одна оранжевая искра. Цена набирается антиквой, «от» — курсивом.

Правила

Медная рамка-паспарту на всех форматах кроме 728×90. Не больше одной кнопки. Курсив — только для одного слова в заголовке.

Контент для соцсетей · концепт контента
